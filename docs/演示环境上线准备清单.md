# 演示环境上线准备清单

状态：代码已准备，未执行公网部署。

本清单用于把仓库部署为公开可访问的产品演示。它不是商业生产上线方案：访客只能填写虚构资料，解锁不产生金额或订单，报告不构成医疗建议。

## 1. 建议拓扑

```text
GitHub 仓库 → Vercel（Next.js）→ Neon（独立演示 PostgreSQL）
                         └→ 每日到期数据清理任务
```

项目依赖 Route Handlers、HttpOnly Cookie 和 PostgreSQL，不能改成纯静态导出。Vercel 可直接识别 Next.js；`postinstall` 会生成 Prisma Client，生产构建使用 `npm run build`。

## 2. 外部资源

- 一个仅供本演示使用的 Neon 数据库，不复用个人或商业生产库。
- 一个连接 GitHub 仓库的 Vercel 项目。
- 一个稳定的生产域名。可以先使用 Vercel 分配的 `*.vercel.app` 域名。
- 一个至少 32 位的随机 `CRON_SECRET`，只配置在部署平台，不写入仓库。

## 3. 环境变量

在 Vercel Production 环境配置：

```dotenv
APP_ENV="demo"
APP_ORIGIN="https://项目名.vercel.app"
DATABASE_URL="Neon 运行时连接串（建议使用连接池地址）"
DIRECT_URL="Neon 直连串（供迁移使用）"
MOCK_PAYMENTS_ENABLED="true"
DEMO_MODE="true"
DEMO_PAID_SESSION_ID="00000000-0000-4000-8000-000000000010"
DEMO_PAID_ASSESSMENT_ID="00000000-0000-4000-8000-000000000020"
SESSION_CREATION_LIMIT_PER_MINUTE="60"
CRON_SECRET="至少 32 位随机字符串"
```

注意：

- `APP_ENV=demo` 是本应用的能力开关；Vercel 仍会使用标准的 `NODE_ENV=production` 构建。
- `APP_ORIGIN` 必须是浏览器地址栏中的精确 HTTPS Origin，不能带路径或尾部配置项。
- 随机 Preview 域名不会自动匹配固定 `APP_ORIGIN`，因此完整写流程只验收稳定的 Production `vercel.app` 域名。
- 不要把连接串或 `CRON_SECRET` 添加到 `NEXT_PUBLIC_` 变量。

## 4. 首次数据库准备

在受控终端中临时加载同一套数据库变量后执行：

```shell
npm ci
npm run demo:prepare
```

`demo:prepare` 只执行已提交迁移和固定合成 seed。不要在每次 Vercel 构建中并发执行迁移；Schema 变更应先在独立演示库验证，再由单一受控任务运行。

## 5. 部署前本地门禁

```shell
npm run verify
```

该命令包括 lint、类型检查、单元测试、真实 PostgreSQL 集成测试、Playwright 双视口流程和生产构建。测试库必须与演示库隔离。

如果当前环境只具备 Node.js、没有 PostgreSQL 或 Chromium，至少先运行：

```shell
npm run lint
npm run typecheck
npm run test:unit
npm run build
```

缺少数据库或浏览器时不能把这组检查描述为完整验收。

## 6. 部署后验收

按顺序验证：

1. `GET /api/health` 返回 200。
2. `GET /api/ready` 返回 200，证明数据库和固定合成报告就绪。
3. 无痕窗口访问 `/`，确认“只填写虚构资料”提示可见。
4. 完成一次五阶段测评，刷新后能恢复进度并生成 PREVIEW 报告。
5. 点击“演示解锁”，确认没有金额、订单或第三方支付入口，刷新后仍返回 FULL 报告。
6. 访问 `/demo`，切换基础/完整视图，确认不设置或覆盖个人 Cookie。
7. 访问 `/privacy` 删除本次访客数据，旧 Cookie 随即失效。
8. 使用错误维护凭证调用 `/api/maintenance/purge` 必须返回 401；在 Vercel Cron 日志中确认每日任务成功。

## 7. 数据边界

- 公开演示的普通匿名会话有效期为 1 天，最后一次写入后的数据保留窗口不超过 7 天。
- `vercel.json` 每天 UTC 03:00 调用一次清理接口。该频率符合 Vercel Hobby 的每日调度限制。
- 固定合成 Demo 用户带 `is_demo=true`，自动清理明确排除它；每 30 天运行一次 `npm run demo:refresh` 延长合成样例期限。
- 页面、隐私说明和演示解锁弹窗都明确禁止填写真实健康资料，也不收集姓名、手机号、邮箱或银行卡信息。

## 8. 回滚

- 应用异常：在 Vercel 回滚到上一个已验证部署；不要回滚已经执行的数据库迁移文件。
- Demo 过期：重新执行 `npm run demo:refresh`，再确认 `/api/ready`。
- 数据库迁移异常：停止新写入，保留数据库快照，使用新的前向迁移修复。
- 需要停止公开展示：在 Vercel 禁用 Production 域名或部署保护；不要用删除数据库代替下线。

## 9. 明确未执行

本仓库没有创建 Neon/Vercel 资源、没有写入云端连接串、没有触发 Production Deploy，也没有生成虚假的线上 URL。完成这些操作需要部署账号所有者另行授权和配置。
