## 风险控制

- 所有健康输入只在本地合成测试数据上开发；没有隐私/删除闭环前不采集真实数据。
- 数据库迁移先在独立本地 PostgreSQL 执行；不连接生产或用户现有数据库。
- 模拟支付与公开演示默认关闭，只有 `APP_ENV=demo` 可显式开启。
- 不记录 Cookie、Bearer token、身体数据、数据库连接串或完整报告。
- 当前仓库已配置 Git 远端和 CI 工作流；不执行新的提交、推送或公网部署，除非用户另行授权。
