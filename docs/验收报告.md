## 安全与数据边界

- 会话原始 token 只进入 `HttpOnly` Cookie；数据库只保存 SHA-256 摘要。
- 写请求校验精确 Origin、JSON 类型、16 KiB 上限和严格请求字段；资源查询绑定当前用户。
- 授权前任何问卷答案写入都会返回 `CONSENT_REQUIRED`；多选字段使用闭集枚举并拒绝 `NONE` 冲突。
- 匿名会话创建使用 PostgreSQL 共享容量桶，超限返回 `429` 与 `Retry-After`。
- 免费响应使用字段白名单，不依赖 CSS 隐藏付费数据。
- 模拟支付与公开 demo 默认关闭，生产环境配置禁止开启。
- demo 只读取固定合成身份，不设置 Cookie；客户端定位参数被拒绝。
- 主动删除在用户行锁内清除业务依赖数据；自动清理默认 dry-run，执行时再次锁定并复核期限，排除 demo。
- 超出物理输入范围的数据会被拒绝；目标方向、极端 BMI、大幅变化及能量超出演示窗口时保留真实输入并显示风险提示，不把数值描述为医疗处方。

## 残余风险与外部待办

1. `npm audit --omit=dev` 仍报告 Prisma CLI 经 `@prisma/config` 引入的 `deepmerge-ts`、`effect` 公告。自动修复会降级 Prisma，未使用 `--force`；需跟踪兼容上游版本并重新跑完整质量门。
2. 当前锁定 Playwright 版本对应的 Chromium 下载因外部链路中断；本次用本机已有 Chromium 完成 14 个项目用例。干净环境应运行 `npx playwright install chromium` 后复验。
3. 当前已提供数据库级全局会话创建上限；公网仍需在可信代理或平台层叠加按客户端限流，避免单一来源耗尽全局额度。
4. `APP_ENV=production` 没有真实支付实现，只会明确展示“未开放解锁”；接入真实收款、签名、退款和对账前不能作为商业生产产品。
5. 公网部署后需验证真实域名 Origin、Secure Cookie、数据库最小权限/连接池、备份恢复、监控告警和回滚。
6. 模型和阈值只适用于演示。任何真实健康产品使用前都需要医学、营养、隐私和法务评审。
